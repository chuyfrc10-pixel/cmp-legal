Política de privacidad

Última actualización: 25 de noviembre de 2026.

Content Manager Pro es una aplicación de escritorio de uso personal. Esta política explica qué datos usa y cómo.

Datos de Google que usa

Con tu permiso, la aplicación usa la API de datos de YouTube para subir videos a tu canal, programar su publicación y consultar si ya están públicos. Solo accede a tu propio canal.

Dónde se guardan

El permiso de acceso (token) y la programación se guardan cifrados únicamente en tu computadora. No se envían a ningún servidor del desarrollador ni a terceros. Los videos solo se envían a YouTube.

Qué no hace

No vende, comparte ni usa tus datos para publicidad. No recopila analíticas ni datos de otras personas.

Cómo revocar el acceso

Puedes desconectar la aplicación en cualquier momento desde sus ajustes o en myaccount.google.com/permissions. Al desinstalarla se borran sus datos locales.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La aplicación también usa los Servicios API de YouTube; consulta los Términos de servicio de YouTube y la Política de privacidad de Google.
